FLUXO ATUAL (E2E)
================================================================================

1. Usuário vê produto em /shop/vitrine
2. Clica produto → /shop/product/:id
3. Clica "Adicionar ao carrinho"
   └─ Chama: addToCart(CartItemRequest)
   └─ Envia: POST /marketplace/cart/items
4. Clica ícone carrinho → /shop/cart
   └─ Mostra: itens, quantidades, preço, botão checkout
5. Clica "Ir para Checkout" → /shop/checkout
   └─ Preenche: endereço, dados cliente, envio, pagamento
6. Clica "Confirmar Pedido" → checkout(CheckoutRequest)
   └─ Envia: POST /marketplace/orders
   └─ Backend cria Order (status="pending")
7. App navega → /shop/checkout/payment/:orderId
   └─ Mostra: Order ID + mock de pagamento (PIX)
   └─ ❌ NÃO chama createPayment() de verdade
   └─ ❌ NÃO integra Wolknow
8. Clica "Meus Pedidos" → /shop/orders
   └─ ❌ Placeholder (não implementado)

COMO TESTAR AGORA (E2E)
================================================================================

1. Start backend:
   $ cd Brawe/backend && python -m app.main

2. Start connect (pagamentos):
   $ cd Brawe/brawe-connect/backend
   $ python -m uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload

3. Start app:
   $ cd brawe-app && flutter run

4. Teste:
   a) Navega /shop/vitrine
   b) Clica produto → /shop/product/:id
   c) Clica "Adicionar" → deve aparecer em /shop/cart
   d) Em /shop/cart, edita quantidade → deve atualizar
   e) Clica "Checkout" → /shop/checkout
   f) Preenche formulário (todos os campos obrigatórios)
   g) Clica "Confirmar" → Backend cria Order, app navega a /shop/checkout/payment/:id
   h) Vê mock de PIX (QR code placeholder)

5. Verifica no backend:
   - GET /marketplace/orders/:id → Vê Order criada ✅
   - Check affiliate_id → Se foi enviado, verá no Order ✅
   - Check affiliate_commission_amount → Se foi calculado, verá aqui ✅
