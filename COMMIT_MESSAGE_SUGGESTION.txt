## Summary
Fixes critical onboarding bug where new users were stuck on the
profile completion screen.

## Problem
After users completed their profile with avatar, username, and other
details, they remained stuck on `/edit-profile` instead of being
redirected to the feed.

## Root Cause
`EditProfileScreen._onSave()` was not updating the `authStateProvider`
after successful profile save. The router continues to observe the old
user state (with empty avatarUrl) and forces redirect back to
`/edit-profile`.

## Solution
Update `authStateProvider` with the new user data after profile save
and navigate to `/home`, following the pattern established in
`LoginViewModel` and `SignupViewModel`.

## Changes
- Add imports for `authRepositoryProvider` and `authStateProvider`
- After profile save success, fetch updated user from backend
- Update auth state via `authStateProvider.notifier.updateSession()`
- Navigate to `/home` (feed)

## Testing
- [x] Tested on Android emulator
- [x] Tested on iOS simulator
- [x] New user signup → profile completion → feeds works ✓
- [x] Back button works correctly
- [x] Logout/login doesn't break
- [x] No compilation errors

✅ Fully backward compatible with published versions
