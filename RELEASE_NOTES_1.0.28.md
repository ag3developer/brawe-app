# Release Notes - Brawe v1.0.28+28

## 🇧🇷 Português (PT-BR)

### O que está incluído nesta versão

✨ **Novas Funcionalidades:**
- Perfil: agora mostra a data de criação real do usuário
- Indicador online: status em tempo real (verde quando usuário está online)
- Aba Posts: exibe todos os tipos de conteúdo (texto, fotos e vídeos unificados)

🎨 **Melhorias Visuais:**
- Grid de vídeos: proporção corrigida para 3:4 (Instagram Stories)
- Overlays de vídeos: melhor visibilidade (likes, views, captions)
- Labels: "Sounds" sem truncamento em telas pequenas

🐛 **Correções de Bugs:**
- Novo usuário agora é redirecionado corretamente após salvar perfil na onboarding
- Página Explore carrega categorias de lives sem erros
- Sincronização de dados de perfil melhorada

🚀 **Backend:**
- 242 lives com categorias validadas
- Sistema de categorias mais robusto

---

## 🇺🇸 English (EN-US)

### What's included in this version

✨ **New Features:**
- Profile: now displays the user's real creation date
- Online indicator: real-time status (green when user is online)
- Posts tab: displays all content types (text, photos, and videos unified)

🎨 **Visual Improvements:**
- Video grid: corrected aspect ratio to 3:4 (Instagram Stories)
- Video overlays: improved visibility (likes, views, captions)
- Labels: "Sounds" without truncation on small screens

🐛 **Bug Fixes:**
- New user now correctly redirected after saving profile in onboarding
- Explore page loads live categories without errors
- Improved profile data synchronization

🚀 **Backend:**
- 242 lives with validated categories
- More robust category system

---

## 🇪🇸 Español (ES-ES)

### Qué hay incluido en esta versión

✨ **Nuevas Características:**

- Indicador en línea: estado en tiempo real (verde cuando el usuario está en línea)

🐛 **Correcciones de Errores:**

- 242 lives con categorías validadas
- Sistema de categorías más robusto
